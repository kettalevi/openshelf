File format

The first row must be a header. Required columns: sku and name. Optional columns: {% for c in columns if c not in ('sku', 'name') %}{{ c }}{{ ', ' if not loop.last }}{% endfor %}.

  • Rows are matched to existing products by SKU: matching products are updated, new SKUs are created.
  • Empty cells leave existing values unchanged.
  • If quantity differs from current stock, the difference is recorded as a stock movement.
  • Categories that do not exist yet are created.
  • If any row has a problem, nothing is imported.

Tip: export your products to get a file in exactly this format.
